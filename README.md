## Bus Ticketing Platform

Current repo status:

- Backend: FastAPI + SQLAlchemy + MySQL
- Frontend: React + Vite with a custom CSS design system
- Implemented areas already include auth, admin basics, operator basics, booking search, and segment-based seat booking APIs

Important note:

- The original planning prompt mentions Tailwind CSS, but the current checked-in frontend is built with modular CSS and CSS variables instead.
- This README reflects the actual codebase so project expectations stay aligned while we continue improving the app.
